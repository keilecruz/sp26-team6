# GlowUp Documentation

This folder contains the main documentation files for the GlowUp project.

## Project Overview

GlowUp is a web-based beauty and grooming service platform. Customers can browse beauty professionals, view provider profiles, book appointments, and leave reviews. Providers can manage their professional profile, services, availability, bookings, sample work gallery, and customer reviews.

## Documentation Files

### GlowUp_SRS.md
This file contains the Software Requirements Specification for the project. It includes the project vision, glossary, user roles, scope, functional requirements, non-functional requirements, assumptions, constraints, milestones, and change management plan.

### GlowUp_Reqs_Testing_Plan.md
This file contains the requirements testing plan. It explains how the main customer and provider use cases should be tested, including expected outcomes for each feature.

### UML-case.png
This image shows the use case diagram for the GlowUp system. It explains the main actions available to customers and providers.

### UML_Class.png
This image shows the class design for the system. It explains the main entities and relationships used in the project.

### GlowUp Presentation.pptx
This file contains the project presentation slides for explaining the app, features, design, and final implementation.

## Provider-Side Features

The provider side of GlowUp includes:

- Provider dashboard
- Provider profile management
- Sample work gallery
- Services management
- Availability management
- Customer reviews and average rating
- Booking visibility
- Booking confirmation from PENDING to CONFIRMED

## Customer-Side Features

The customer side of GlowUp includes:

- Customer dashboard
- Browse professionals
- View provider profiles
- Book appointments
- View customer appointments
- Write reviews

## Notes

This project is a CSC 340 semester prototype. Some production-level features, such as online payments, real-time messaging, and notifications, are outside the current project scope.
